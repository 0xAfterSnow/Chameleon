# Brand assets

This demo uses the existing goChameleon black-and-lime logo and emerald artwork, intentionally included at the owner's request. It matches the product's Mona Sans typography, IBM Plex Mono technical labels, cool gray surfaces, emerald controls and rounded cards.

All assets are local to `demo/public/assets`; the copied repository has no dependency on the private frontend or a font CDN. Only brand artwork and licensed fonts were copied, not production application code. Font license notices are preserved in `docs/licenses/`. Those notices apply to the fonts; they do not grant rights to the goChameleon brand or change the demo's pending application license.
